# 파이썬 첫걸음 · 10분 수업

파이썬을 처음 만나는 사람을 위한 한국어 소개 페이지입니다. 네 가지 핵심 개념을 배우고, 브라우저 안에서 코드를 수정·실행할 수 있습니다.

## 페이지 열기

GitHub Pages가 배포되면 다음 주소에서 확인할 수 있습니다.

https://dknife.github.io/2026PythonIntro/

## 구성

- `index.html`: 수업 페이지와 Pyodide 기반 코드 실습
- `assets/images/fig01.webp`–`fig05.webp`: 표지 및 개념 삽화
- `.github/workflows/pages.yml`: `main` 변경 시 GitHub Pages 자동 배포

Pyodide는 첫 코드 실행 때 CDN에서 내려받으므로 인터넷 연결이 필요합니다.

## 출처와 사용

이 서비스는 Codex를 이용한 바이브 코딩으로 제작했으며, 이미지는 Gemini로 생성했습니다. 페이지 콘텐츠는 누구나 자유롭게 사용할 수 있습니다.

참고 자료: [Python 공식 튜토리얼](https://docs.python.org/3/tutorial/), [Pyodide 사용 안내](https://pyodide.org/en/stable/usage/index.html), [Pyodide JavaScript API](https://pyodide.org/en/stable/usage/api/js-api.html).
